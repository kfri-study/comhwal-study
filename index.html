적용 범위의 첫 셀을 기준으로 수식을 작성한다. 값은 그대로 두고 표시만 바꾼다.

Excel · 기본작업
인쇄와 보호페이지 레이아웃 · 시트 보호

인쇄 영역과 반복할 제목 행은 출력 방식에 영향을 준다. 잠긴 셀은 시트 보호를 적용해야 편집이 제한된다.

Excel · 기본작업
조건 분기IF · IFERROR

IF는 조건의 참과 거짓에 따라 값을 고른다. IFERROR는 계산 오류일 때만 대체값을 낸다.

Excel · 계산작업
찾기VLOOKUP · MATCH · INDEX

VLOOKUP은 표 첫 열에서 찾는다. MATCH는 위치, INDEX는 그 위치의 값을 돌려준다.

Excel · 계산작업
문자LEFT · MID · RIGHT

왼쪽·지정 위치·오른쪽에서 글자를 꺼낸다. 추출 결과는 숫자처럼 보여도 텍스트다.

Excel · 계산작업
조건별 집계SUMIFS · COUNTIFS

같은 조건들로 금액을 더할 때는 SUMIFS, 행 수를 셀 때는 COUNTIFS를 쓴다.

Excel · 계산작업
여러 조건배열 계산

조건별 참·거짓을 곱하면 두 조건이 모두 참인 행만 1이 남는다. 문제에서 지정한 함수와 입력 방식을 확인한다.

Excel · 계산작업
직접 정의사용자 정의 함수

VBA에서 Function으로 함수를 정의하고 함수 이름에 계산 결과를 대입한다. 시트에서는 내장 함수처럼 =함수이름(인수)로 호출한다.

Excel · 계산작업
요약피벗 테이블

행·열에는 분류 기준, 값에는 집계할 필드를 둔다. 숫자 필드의 요약 방식이 합계인지 개수인지 확인한다.

Excel · 분석작업
원본외부 데이터 가져오기

Access 테이블이나 쿼리를 원본으로 선택해 Excel로 가져온다. 지시된 원본 이름과 대상 위치를 맞춘다.

Excel · 분석작업
가정 분석목표값 찾기

원하는 결과, 수식 셀, 변경할 입력 셀 하나를 구분한다.

Excel · 분석작업
집계부분합

같은 항목이 인접하도록 기준 열로 먼저 정렬하고 그룹마다 합계나 평균을 낸다.

Excel · 분석작업
차트차트 영역 · 차트 제목 · 데이터 계열

같은 글꼴이나 채우기 명령도 선택한 대상에만 적용된다. 원하는 요소 이름을 확인하고 수정한다.

Excel · 기타작업
자동화매크로 기록

반복할 동작을 기록한 뒤 도형이나 단추에 연결한다. 재실행할 때도 같은 위치에 결과가 생기는지 본다.

Excel · 기타작업
VBA이벤트 프로시저

단추를 누르는 Click처럼 특정 동작이 코드를 실행한다.

Excel · 기타작업
셀 접근Cells · Range

Cells(행, 열)은 숫자로, Range("B2")는 주소로 셀을 가리킨다.

Excel · 기타작업
구조필드 · 레코드

필드는 열 하나의 성질, 레코드는 한 건의 데이터다. 필드 형식은 저장할 값에 맞춘다.

Access · DB 구축
식별기본 키 · 외래 키

기본 키는 한 건을 구별한다. 외래 키는 다른 테이블의 기본 키를 참조한다.

Access · DB 구축
입력 제한입력 마스크 · 유효성 검사 규칙

마스크는 입력 모양을, 검사 규칙은 허용할 값을 제한한다. 유효성 검사 텍스트는 오류 때 보여 줄 문구다.

Access · DB 구축
관계참조 무결성

상위 테이블에 없는 키로 하위 레코드를 만들지 못하도록 관계에 제약을 둔다.

Access · DB 구축
폼레코드 원본 · 컨트롤 원본

레코드 원본은 폼 전체의 데이터이며 컨트롤 원본은 특정 입력 상자가 연결할 필드나 식이다.

Access · 입력 및 수정
목록행 원본 · 바운드 열

행 원본은 콤보 상자의 선택 목록이다. 바운드 열은 선택 시 실제로 저장되는 열이다.

Access · 입력 및 수정
계산IIf · Nz

IIf는 조건에 따라 둘 중 하나를 반환하고 Nz는 Null을 지정 값으로 대체한다.

Access · 입력 및 수정
연결기본 폼 · 하위 폼

연결 필드로 현재 기본 폼 레코드에 속한 상세 행만 표시한다.

Access · 입력 및 수정
조회Filter · FilterOn

필터 조건을 지정한 뒤 FilterOn을 켜야 폼에 적용된다.

Access · 조회 및 출력
보고서본문 · 그룹 바닥글 · 보고서 바닥글

본문은 레코드마다, 그룹 바닥글은 그룹마다, 보고서 바닥글은 전체의 끝에 나온다.

Access · 조회 및 출력
집계Sum · Count

Sum은 값의 합, Count(*)는 레코드 수를 센다. 같은 식도 어느 구역에 두는지에 따라 결과 범위가 달라진다.

Access · 조회 및 출력
실행DoCmd.OpenReport

보고서 이름, 보기 방식, 조건을 지정해 일부 레코드만 미리 볼 수 있다.

Access · 조회 및 출력
조회선택 쿼리 · 매개 변수

선택 쿼리는 결과를 표시한다. 조건에 [지역을 입력하세요]를 쓰면 실행 때 입력을 받는다.

Access · 처리 기능
요약그룹화 · 집계

같은 기준으로 묶고 합계나 개수를 계산한다. SQL에서 WHERE는 집계 전 행을, HAVING은 집계한 그룹을 거른다.

Access · 처리 기능
변경추가 · 업데이트 · 삭제 쿼리

각각 새 행을 넣거나 기존 값을 바꾸거나 행을 없앤다. 연습용 복사본에서 대상 행부터 확인한다.

Access · 처리 기능
교차 집계크로스탭 쿼리

행 머리글·열 머리글·값을 정해 두 기준이 교차하는 위치에 집계 결과를 표시한다.

각각 새 행을 넣거나 기존 값을 바꾸거나 행을 없앤다. 연습용 복사본에서 대상 행부터 확인한다.

교차 집계크로스탭 쿼리

행 머리글·열 머리글·값을 정해 두 기준이 교차하는 위치에 집계 결과를 표시한다.

직접 연습하기

지역별 주문 건수는 SELECT [지역], Count(*) AS [건수] FROM [주문] GROUP BY [지역]; 로 확인한다. 결과의 건수 합을 원본 행 수와 비교한다.

스스로 확인
